🤖 ChatMCA: An AI Chat Application
Welcome to ChatMCA! This is a powerful, web-based chatbot built with Python (Django) and the Google Gemini API 🧠. The goal was to create a fast, dynamic, and modern chat experience with a UI inspired by Google's own Gemini interface.

✨ Features
🚀 Real-time Streaming: Bot responses are streamed word-by-word. No more waiting!

📚 Persistent History: Refresh the page and your conversation is still there, saved to the database.

💡 Smart Suggestions: AI-generated follow-up prompts appear after each response.

🎨 Gemini-Inspired UI: A clean, light-themed, and fully responsive user interface.

📋 Copy to Clipboard: Easily copy any bot message with a single click.

🛑 Stop Generating: Interrupt the bot at any time.

💻 Code Highlighting: Renders code blocks with correct syntax highlighting.

🛠️ Tech Stack
Backend: Django

Frontend: HTML | CSS | Vanilla JS

AI: Google Gemini API

Database: SQLite

🚀 How to Run
Clone: git clone https://github.com/YOUR_USERNAME/ChatMCA.git

Install: pip install -r requirements.txt

API Key: Set your GEMINI_API_KEY as an environment variable.

Migrate: python manage.py migrate

Run: python manage.py runserver

And you're live at http://127.0.0.1:8000/!
